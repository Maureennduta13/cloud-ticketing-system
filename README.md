# # Cloud-Based IT Ticketing System

A cloud-focused IT support ticketing system built as a hands-on Cloud Engineering portfolio project.

The project will progressively evolve from a local Flask application into a cloud-hosted, automated and monitored application using Google Cloud Platform.

## Project Goal

The goal of this project is to build a functional IT ticketing system while developing practical Cloud Engineering skills.

The system will eventually demonstrate:

- Application development
- Linux
- Networking
- Google Cloud Platform
- Cloud databases
- IAM and security
- Docker
- Terraform
- CI/CD
- Monitoring and logging
- Git and GitHub

## Current Technology Stack

- Python

- HTML

- SQLite
- Git
- GitHub
